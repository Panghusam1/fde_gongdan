原五天任务现已无删减压缩为三天：第一天完成数据库与检索策略，第二天搭建协调助手并跑通完整工单，第三天完成40题扩展、联调、准确率优化、部署设计、演示、总结和面试材料。详细验收见[三天全量交付计划](docs/three-day-delivery-plan.md)、[第三天完整教学](docs/lessons/day3-05-integration-deployment-accuracy-complete.md)和[部署运行手册](docs/deployment/test-and-production-deployment-runbook.md)。

## 已确定的边界

- 案例设备：施耐德 Altivar Machine ATV320 变频器。
- 首个故障场景：OHF 变频器过热。
- 本地数据库：PGlite。
- 向量能力：pgvector。
- 正式生产迁移目标：服务端 PostgreSQL + pgvector。
- 原始资料必须来自可核验来源；模拟厂区和工单必须明确标注为模拟数据。
- 涉及拆机、带电测量、更换部件或安全参数修改时，系统转人工。
