# 数据库不可违反规则（第一版）

这份文件是数据库设计和审查的共同依据。规则不是由表结构反推出来的；表结构必须服从这些规则。

| 编号 | 不可违反的规则 | 第一版执行方式 | 验证方式 |
|---|---|---|---|
| R01 | 每台设备必须属于一个真实存在的厂区 | 设备表使用非空厂区外键 | 插入无厂区设备必须失败 |
| R02 | 每张工单必须对应一台真实存在的设备 | 工单表使用非空设备外键 | 插入不存在设备的工单必须失败 |
| R03 | 工单厂区必须与设备所属厂区一致 | 后续使用复合外键约束 | 跨厂区设备工单必须失败 |
| R04 | 每个知识片段必须属于一个真实存在的资料版本 | 知识片段使用非空资料版本外键 | 插入孤立片段必须失败 |
| R05 | 知识片段必须保存可阅读原文，不能只有向量 | 原文字段非空并检查去除空白后长度 | 空原文必须失败 |
| R06 | 同一逻辑资料的相同版本、语言和文件指纹不得重复导入 | 去除空格并忽略大小写的联合唯一索引 | 换路径重复导入同一文件必须失败 |
| R07 | 工单状态只能使用预先规定的状态 | 文本字段加检查约束 | 非法状态必须失败 |
| R08 | 高危工单必须进入人工处理状态 | 数据库约束加应用流程测试 | 高危工单绕过人工必须失败 |
| R09 | 已完成人工审批必须记录审批人和审批时间 | 表级检查约束 | 不完整审批记录必须失败 |
| R10 | 工单和初始事件必须整体成功或整体撤销 | 短事务 | 人为制造中途失败后不得留下半张工单 |
| R11 | 高危工单只能由有权限的人工工程师确认解决 | 状态转换服务、角色校验和人工处理记录 | AI或普通用户解决高危工单必须失败 |
| R12 | 普通工单只能在AI给出有证据的低风险方案且现场用户确认实际恢复后进入已解决 | 方案、确认记录和状态转换校验 | AI直接解决或无用户确认时必须失败 |
| R13 | 工单只有在存在有证据且通过低风险检查的方案时才能进入等待用户确认 | 方案、引用证据、风险判断和状态转换校验 | 缺方案、缺证据或高危方案进入该状态必须失败 |
| R14 | 同一工单最多生成两版低风险方案，且第二版必须基于新增有效证据 | 方案版本、证据关联和状态转换校验 | 第三版或无新增证据的第二版必须失败 |
| R15 | 同一个外部身份只能对应一个系统用户 | 用户外部身份唯一约束 | 重复外部身份必须失败 |
| R16 | 厂区成员关系必须同时引用真实用户和真实厂区 | 两个非空外键 | 孤立成员关系必须失败 |
| R17 | 厂区角色只能是操作员、工程师、主管或管理员 | 角色检查约束 | 非法角色必须失败 |
| R18 | 同一用户在同一厂区的同一角色只能授权一次 | 三列唯一约束 | 重复授权必须失败 |
| R19 | 同一厂商下的同一标准产品系列只能登记一次 | 厂商与系列代码联合唯一约束 | 重复产品系列必须失败 |
| R20 | 同一产品系列下的同一具体型号只能登记一次 | 系列与型号代码联合唯一约束 | 重复具体型号必须失败 |
| R21 | 每台现场设备必须引用一个真实存在的规范型号 | 非空规范型号外键 | 不存在规范型号的设备必须失败 |
| R22 | 新设备以规范型号为正式依据，不要求重复填写厂商、系列和型号自由文本 | 规范型号外键加可空原始输入字段 | 只提供规范型号的新设备必须成功 |
| R23 | 升级已有数据库时必须保留旧设备并自动建立规范型号关联 | 数据回填迁移 | 在旧结构插入设备后执行升级，设备和原始型号都必须保留 |
| R24 | 工单创建人必须使用该工单厂区内的真实成员身份 | 工单厂区与创建成员复合外键 | 其他厂区成员创建工单必须失败 |
| R25 | 工单事件的厂区必须与所属工单厂区一致 | 事件与工单复合外键 | 跨厂区伪造事件必须失败 |
| R26 | 用户事件必须记录同厂区成员身份，AI和系统事件不能冒用人员身份 | 参与者类型与成员字段检查约束、复合外键 | 缺失或错误的人员身份必须失败 |
| R27 | 同一工单中的同一幂等键只能产生一条事件 | 工单与幂等键联合唯一约束 | 网络重试产生重复事件必须失败 |
| R28 | 已写入的工单事件不能更新或删除，只能追加更正事件 | 更新与删除阻断触发器 | 修改或删除历史事件必须失败 |
| R29 | 成功创建草稿工单时必须同时写入第一条创建事件 | 统一创建服务与短事务 | 成功后同时查到工单和创建事件 |
| R30 | 已停用的厂区成员不能创建新工单 | 创建服务检查成员启用状态 | 停用成员创建工单必须失败且不留数据 |
| R31 | 已停用的系统用户不能通过旧成员关系创建新工单 | 创建服务同时检查用户启用状态 | 停用用户创建工单必须失败且不留数据 |
| R32 | 工单不能跳过状态机规定的路径 | 状态转换服务使用明确转换表 | 草稿直接进入已解决必须失败 |
| R33 | 合法状态转换必须同时更新当前状态并追加状态事件 | 条件更新与事件插入使用同一短事务 | 成功后当前状态和事件必须一致 |
| R34 | 状态事件写入失败时当前状态也必须回滚 | 同一短事务 | 制造事件唯一冲突后工单状态必须保持原值 |
| R35 | 已停用的用户或成员不能执行状态转换 | 状态转换服务检查活动成员 | 停用成员转换状态必须失败 |
| R36 | 用户账号停用后不能通过仍存在的成员关系转换工单状态 | 状态转换服务同时检查用户启用状态 | 停用用户转换状态必须失败 |
| R37 | 每份官方资料必须引用一个真实存在的规范产品系列 | 非空规范产品系列外键 | 缺少系列或引用不存在系列必须失败 |
| R38 | 旧资料升级时只能连接已经存在且名称吻合的规范系列，不能由迁移猜造主数据 | 规范化匹配后回填，未匹配记录阻断迁移 | 已确认系列成功连接且原始文字保留 |
| R39 | 官方资料类别只能使用正式手册、数据表、维修通告或安全通知 | 类别检查约束 | 拼写错误或未设计类别必须失败 |
| R40 | 新导入的资料版本在人工核验前不能自动成为当前有效版 | 版本状态默认“待审核” | 省略状态导入后必须为待审核 |
| R41 | 版本状态只能是待审核、当前有效、已被取代或已撤回 | 状态检查约束 | 未定义状态必须失败 |
| R42 | 同一逻辑资料的同一种语言只能有一个当前有效版本 | 只约束当前有效记录的联合唯一索引 | 第二个当前有效版必须失败，历史版仍可保留 |
| R43 | 同一发布机构和文件编号不能因大小写或前后空格重复建档 | 规范化后的联合唯一索引 | 变换大小写或空格重复建档必须失败 |
| R44 | 官方资料清单中的文件指纹必须与本地文件一致，重复执行导入不能生成副本 | 文件指纹校验、数据库唯一索引和可重复执行种子 | 篡改文件时测试失败，连续导入两次仍只有一个版本 |
| R45 | 同编号资料已存在但规范系列或资料类别冲突时，正式导入不能静默跳过 | 种子事务内显式一致性检查 | 预置错误系列后导入必须整批失败 |
| R46 | 厂商下载页面日期和PDF内部版次月份必须分别保存 | 网页日期字段加原样版次标签 | NVE41300 同时保留 2025-07-04 和 07/2024 |
| R47 | 每个PDF页面身份必须属于真实存在的资料版本 | 非空资料版本外键 | 孤立页面必须失败 |
| R48 | PDF页序必须从1开始 | 正数检查约束 | 0页和负数页必须失败 |
| R49 | 同一资料版本的同一PDF页只能登记一次 | 资料版本与PDF页序联合唯一索引 | 重复页面身份必须失败 |
| R50 | 提取方式只能是直接文字层、OCR或人工录入 | 提取方式检查约束 | 未设计的“魔法AI”方式必须失败 |
| R51 | 提取状态只能是已抽取、空白、需要OCR或失败 | 提取状态检查约束 | 未定义状态必须失败 |
| R52 | 提取状态必须与正文和正文指纹一致 | 跨字段检查约束 | 空白状态带正文、已抽取状态无正文都必须失败 |
| R53 | 每份页面抽取结果必须记录非空工具名称和版本 | 非空白检查约束 | 缺工具或缺版本必须失败 |
| R54 | 真实PDF的页级中间文件必须页序连续、逐页正文指纹可复算 | 生成脚本加自动测试 | 440页连续，三张空白页与OHF代表页都必须吻合 |
| R55 | 同一PDF页必须允许保留不同工具或配置的提取结果 | 页面身份与提取结果分表 | pypdf与Docling结果可以并存 |
| R56 | 每份页面提取结果必须属于真实存在的PDF页 | 非空页面外键 | 孤立提取结果必须失败 |
| R57 | 同一页面、方式、工具版本和配置只能保存一份结果 | 规范化联合唯一索引 | 相同提取器身份重复保存必须失败 |
| R58 | 合格页级文件必须在一个短事务中批量写入页面和提取结果 | TypeScript批量导入服务 | 一次写入440页和440份基线结果 |
| R59 | 页级文件的来源PDF指纹必须与资料版本一致 | 导入前指纹比对 | 来源指纹被篡改时不得留下页面 |
| R60 | 每页正文必须与页级文件中记录的正文指纹一致 | 导入前逐页重算 | 篡改第72页正文时整批拒绝 |
| R61 | 任一提取结果写入失败时页面身份也必须全部回滚 | 两批写入共用短事务 | 最后一页非法时两张表都不得留下半成品 |
| R62 | 完全相同的页级文件重复导入必须幂等 | 唯一索引加冲突跳过 | 第二次导入新增数为0且总数不变 |
| R63 | 同一提取器身份出现不同正文时不能被幂等逻辑静默掩盖 | 事务内回读并比较状态与正文指纹 | 同工具同版本正文变化必须报冲突 |
| R64 | 整本资料的页级文件不能缺页、重复或乱序 | 导入前连续页序校验 | 删除第72页后整批拒绝 |
| R65 | 缺少页级提取依赖时必须给出可执行的安装方法 | 工具启动前依赖检查 | 隔离第三方包后显示安装命令且不输出调用栈 |
| R66 | 页级提取工具必须锁定已经验证的 pypdf 版本 | Python 依赖清单 | 依赖清单缺失或版本漂移时测试失败 |
| R67 | 未分类知识片段不能因数据库升级自动获得使用资格 | 内容种类和危险等级默认待分类、用途默认仅供查阅、状态默认待审核 | 省略分类字段导入后必须进入保守状态 |
| R68 | 知识片段内容种类只能使用统一词表 | 内容种类检查约束 | 随意编造分类名必须失败 |
| R69 | 资料原文危险等级只能使用手册定义相符的统一词表 | 危险等级检查约束 | 随意编造危险等级必须失败 |
| R70 | 系统允许用途只能是仅供查阅、低风险指导或工程师专用 | 用途检查约束 | 未设计用途必须失败 |
| R71 | 带小心、警告或危险标识的原文不能成为低风险现场指导 | 危险等级与用途的跨字段检查 | “危险+低风险指导”组合必须失败 |
| R72 | 知识片段审核状态只能是待审核、已通过或已驳回 | 审核状态检查约束 | 模型自创“自动通过”等状态必须失败 |
| R73 | 没有完整分类和人工审核证据的片段不能通过 | 多字段审核完整性检查 | 只修改状态为已通过必须失败 |
| R74 | 已通过片段必须同时保留机器原文和人工核对正文 | 原文不可覆盖、核对正文非空 | `1 18%` 原文和 `118%` 核对值必须同时可查 |
| R75 | 已驳回片段必须留下审核人、时间和原因，且不能伪装成已核对正文 | 驳回状态组合检查 | 无理由驳回失败，合法驳回不带核对正文 |
| R76 | 审核人必须是真实存在的系统用户 | 审核人外键及索引 | 伪造审核人编号必须失败 |
| R77 | 三维分类升级不能静默删除旧风险标签数据 | 旧字段改名保留，新字段使用保守默认值 | 从迁移011升级后旧值仍可查且正式旧字段名不再存在 |
| R78 | 每个知识片段来源必须能回查具体页面和具体提取结果 | 独立片段来源关系表 | 从片段反查PDF页码、提取工具和版本 |
| R79 | 片段来源声明的资料版本必须与片段一致 | 片段编号与版本编号组合外键 | 05版片段填写04版来源版本必须失败 |
| R80 | 片段来源声明的页面必须属于同一个资料版本 | 页面编号与版本编号组合外键 | 05版关系引用04版页面必须失败 |
| R81 | 片段来源声明的提取结果必须属于同一个页面 | 提取结果编号与页面编号组合外键 | 第72页关系引用第50页提取结果必须失败 |
| R82 | 片段来源顺序必须从正数开始 | 正数检查约束 | 0和负数顺序必须失败 |
| R83 | 同一片段不能有两个相同来源顺序 | 片段编号与来源顺序唯一约束 | 两条来源都标为第1条必须失败 |
| R84 | 同一片段不能重复保存同一提取结果中的同一文字范围 | 片段、提取结果、起点和终点联合唯一约束 | 同一范围换顺序重复添加必须失败，不同范围允许共存 |
| R85 | 没有具体页面提取来源的片段不能通过审核 | 审核前来源存在性触发器 | 分类和审核留痕完整但无来源时仍必须失败 |
| R86 | 绑定有效来源后片段可以按审核流程通过 | 候选、来源、审核三步写入 | 从已通过片段反查页码、工具和版本 |
| R87 | 已保存的页面提取结果不能原地更新或删除 | 页面提取结果不可变触发器 | 同时修改正文和指纹或删除记录都必须失败 |
| R88 | 片段审核完成后来源关系不能增删改 | 已审核来源不可变触发器 | 通过后替换、删除或追加来源必须失败 |
| R89 | 片段审核完成后正文、分类和记录不能更新或删除 | 已审核片段不可变触发器 | 通过后改正文或删除片段必须失败 |

## 数据库以外仍需验证的内容

- 厂商资料原文是否提取准确。
- 知识片段是否破坏原义或遗漏安全警告。
- 自动切片规则能否在整本手册的表格、跨页段落和警告框上保持结构；当前只验证了首批OHF候选。
- 审核人的真实资质材料和授权流程是否可信；当前数据库只能证明管理员已经把账号授权到某个产品族。
- 型号标签是否符合资料适用范围。
- PGlite 无法证明正式服务端的多连接并发能力。
- 工业维修结论仍需由具备资质的专业人员确认。
- 当前40题由项目组基于6个候选编写，不是真实工厂查询分布；E5首位76.7%、前三100%和错型号5/5只属于该开发集。
