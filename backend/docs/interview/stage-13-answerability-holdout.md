# 阶段十三面试题：无答案阈值留出测试

## 30秒介绍

40题开发集上，0.86看起来能分开可回答和无答案问题。我没有直接上线，而是先冻结24题留出集、题库摘要和三项门槛。第一次真实E5运行后，可回答正确接收91.7%，但无答案拒答只有83.3%，被接收结果准确率84.6%，后两项失败。因此我保留R203失败报告，不调整阈值、不接入主链路，并继续让数据库知识用途和风险门阻止错误候选生成方案。

## 高频问题

### 1. 为什么相似度不能当置信度？

相似度只说明两个向量接近。最近邻算法即使面对完全无关的问题，也会在现有片段中选出“最像的一个”，它不是答案存在概率。

### 2. 为什么不把阈值提高一点？

因为已经看过留出答案，再调就是污染测试集。而且H11的第一名本身排错，阈值只能接收或拒绝，不能修复候选顺序。

### 3. 测试失败后系统安全吗？

阈值没有上线。当前检索结果只是候选；风险门还要求证据经过审核并允许用于低风险指导，否则以证据不足转人工。不能把“检索到了”直接等同于“可以操作”。

### 4. 留出集权威吗？

它比同集调参可靠，但仍是项目组编写的24题，不是真实工厂分布。它能否决一个明显不合格的候选策略，不能证明生产指标。

### 5. 哪些成熟产品使用相似度阈值？

Elastic的kNN产品提供最低相似度参数，因为最近邻总会返回最接近的结果。这个能力说明阈值是常见工具，不说明阈值可以照抄；本项目必须用自己的正负样本校准。

### 6. 下一步是什么？

评估检索后的答案存在性判断：让规则或模型同时阅读问题和候选，判断候选是否直接包含答案；必须用新留出集和人工校准，不能继续在当前24题上追分。

## 问题与调整台账

- 假设：0.86可能区分当前语料有答案和无答案；
- 防作弊：第一次运行前冻结24题、SHA、阈值和门槛；
- 结果：一项通过、两项失败，R203未通过；
- 典型误报：保修售后→热阈值，风扇备件→OHF定义；
- 典型漏报：断电隔离题低于阈值且首位排错；
- 被否决调整：看完分数后上调阈值；
- 当前处理：阈值不接主链，错误候选继续受知识用途和风险门限制；
- 剩余边界：缺真实工单日志、答案存在性模型尚未验证。
