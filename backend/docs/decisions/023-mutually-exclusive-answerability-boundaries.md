# 决策023：证据分类采用互斥顺序，保留“部分相关”和“没有答案”两类

## 状态

已通过已见回归验证；尚待新未见题库验证。

## 触发问题

R233首次四分支真实验收中，WEC03要求判断“通风口堵塞是否就是OHF直接原因”。候选原文提到检查通风口是否被遮挡，但没有OHF或因果关系。第一版模型判为`not_answerable`，预期为`partially_related`，首轮3/4失败。

## 备选方案

| 方案 | 优点 | 缺点 | 决定 |
|---|---|---|---|
| 把标签改成没有答案 | 无需改程序 | 看完结果改答案，破坏留出测试 | 否决 |
| 降低4/4门槛 | 立即显示通过 | 为结果改标准，无法证明修复 | 否决 |
| 合并两种拒答 | 安全逻辑更简单 | 丢失资料缺口，不利于补知识和审计 | 否决 |
| 让三类互斥并规定判断顺序 | 保留细分类价值，边界可测试 | 提示更长，仍需防表面词重合误判 | 采用 |

## 决策

采用“直接回答→部分相关→没有答案”的固定顺序。部分相关要求候选原文明示问题中的关键对象、动作或条件，但缺少所问关系、数值或步骤；没有答案要求没有实质相关候选。

第二版作为独立文件实现，第一版源码、封存记录和失败报告不改写。先单题验证假设，再用已暴露四题回归；结果4/4。因为数据已经暴露，该结果只叫修复回归。

## 代价与后续

第二版可能把只共享表面词语的资料误判为部分相关。下一轮必须新增未见反例，特别测试“同词但业务目的不同”。无论两种拒答如何细分，下游安全策略保持一致：都不得生成方案并转人工。
