# 第三天教学 01：资料身份本身也是证据

## 一句话结论

正文能回答问题，不代表它能回答“指定资料中的内容”；当用户点名资料编号、版本或语言时，来源身份必须和正文一起进入判断器。

## 为什么不是改提示词

提示词写“这是 NVE41300”只是程序员声明，不能证明当前候选真来自该资料。正确做法是从检索命中编号反查数据库外键链，再把查到的资料编号、版本和语言作为结构化字段提供给判断器。

## 为什么不修改旧版

R282 首跑时的代码已经散列封存。直接修改旧文件会破坏历史可复现性，因此新增来源感知适配器和第六版判断器。旧的 11/12 仍是首跑事实，新的 U301 通过只算回归。

## 测试顺序

1. R284 先失败，证明来源适配器不存在；实现后验证真实数据库字段；
2. R285 先失败，证明第六版模型入口不存在；实现后验证两次模型请求；
3. R287 在联网前冻结旧报告、代码和数据库链；
4. R286 用真实千问验证同一问题。

## 面试记忆句

“我没有把文档编号当展示字段，而是当证据的一部分。它由数据库来源链确定，和页码、原文一起进入模型，模型只能核对，不能自报来源。”
