# 第一天第九节：官方资料与版本管理是怎样设计出来的

## 本节做出的东西

不是“下载了一个 PDF”，而是一套能回答以下问题的资料登记底座：

- 这份资料是谁发布的、编号是什么、适用于哪个系列？
- 同一资料有哪些语言和版本？
- 哪一版只是刚导入，哪一版经过审核可以使用？
- 哪些旧版本必须保留但不能默认检索？
- 同一个文件有没有被重复导入？

本节已经取得真实 PDF 并计算文件指纹，但仍未生成页面、知识片段和向量。先把来源身份做对，再处理正文。

## 第一步：先分清“资料”和“文件版本”

以施耐德电气 ATV320 中文编程手册为例：

```text
逻辑资料
└── 发布机构：Schneider Electric
    文件编号：NVE41300
    适用系列：ATV320
    ├── 中文 04 版（历史）
    ├── 中文 05 版（当前候选）
    └── 以后可能出现的中文 06 版
```

`source_documents` 保存上半部分，回答“它是什么”；`source_versions` 保存下半部分，回答“具体是哪一个版本文件”。如果把两者塞在一张表里，标题、发布机构、产品系列会随每个版本重复，当前版也难以约束。

## 第二步：为什么资料必须连接规范产品系列

自由文字会出现：

```text
ATV320
ATV 320
atv320
```

如果资料和设备分别靠这些文字过滤，任何一个空格都可能让正确手册查不到。因此正式关系使用 `product_family_id`；旧导入文字保存在 `raw_product_family`，只用于追查“当时输入了什么”。

升级旧数据时也不能让 AI 用发布机构随意创建厂商。迁移只连接已经存在、且厂商名和系列代码都吻合的规范系列。找不到就失败，要求人核对。

## 第三步：版本为什么默认待审核

下载成功只能证明“拿到了一个文件”，不能证明：

- 它是目前最新且有效的版本；
- 它适用于现场设备的实际配置；
- 它没有被发布方撤回；
- 网页元数据和 PDF 内页信息一致。

所以新版本默认 `unreviewed`（待审核），而不是 `current`（当前有效）。状态含义如下：

| 数据库存值 | 中文含义 | 默认检索是否可用 |
|---|---|---|
| `unreviewed` | 待审核 | 否 |
| `current` | 当前有效 | 是 |
| `superseded` | 已被取代 | 否，历史追溯可查 |
| `withdrawn` | 已撤回 | 否 |

AI可以核对网页、摘要版本差异并给审核人一份完整建议，但不能自己把自己导入的文件批准为当前版。

## 第四步：四条唯一性不是一回事

### 资料身份唯一

`发布机构 + 文件编号` 在去掉前后空格、忽略大小写后唯一，防止同一手册被拆成两份逻辑资料。

### 导入文件唯一

`资料 + 版本 + 语言 + SHA-256 文件指纹` 唯一。即使同一个 PDF 被复制到另一个目录，也会被识别为重复。

### 当前版本唯一

`资料 + 语言` 只在状态为“当前有效”时唯一。这样可以保留很多历史版，同时禁止两个中文版都宣称当前有效。

### 产品系列唯一

资料保存规范产品系列编号，外键保证它不是一个凭空出现的数字。

## 第五步：索引为什么这样排

资料版本经常按“某份资料 + 某种语言”查询，因此联合索引先放资料编号，再放标准化后的语言。限制当前版时使用只包含当前记录的唯一索引，历史版本不进入这个索引。

资料表新增的产品系列是外键。PostgreSQL 不会自动给外键列创建查询索引，因此额外建立 `source_documents(product_family_id)`，供“查某系列全部官方资料”使用。

## 第六步：AI审查数据库设计的正确方式

不能只问 AI：“这个表对吗？”应该把审查拆成四层证据：

1. **业务规则**：先写不可违反的中文句子；
2. **失败测试**：故意插入错误数据，确认数据库真的拒绝；
3. **数据库约束**：外键、检查约束和唯一索引对应到具体规则；
4. **真实样本**：用厂商官方页面的真实编号、版本、语言和产品范围核对字段是否够用。

本轮测试先后真实失败，再补最小数据库实现：

- R37：资料必须引用规范产品系列；
- R38：旧资料安全回填并保留原始文字；
- R39：资料类别必须是允许值；
- R40：新版本默认待审核；
- R41：非法版本状态必须失败；
- R42：同一语言不能有两个当前有效版；
- R06：相同文件指纹不能重复导入；
- R43：逻辑资料不能通过空格或大小写重复建档。
- R44：本地 PDF 指纹必须与资料清单一致，种子重复执行不得产生副本；
- R45：同编号资料已存在但产品系列冲突时，导入必须失败。

这套方法能保证“结构和状态规则是对的”。至于手册正文含义是否正确，下一节必须通过真实 PDF、页级原文、抽取校验和人工抽样继续验证。
