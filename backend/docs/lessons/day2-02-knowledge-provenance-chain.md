# 第二天第二节：让每条知识都能回到具体证据

## 这一节做出了什么

上一节解决“什么知识可以用”，这一节解决“它到底来自哪里”。现在一条已通过知识可以反查：

```text
知识片段
  → 第几个来源
  → 具体页面提取结果
  → pypdf / Docling / 光学识别 / 人工录入
  → 工具版本和配置
  → PDF第几页
  → 哪个资料版本
  → 哪一份官方文件
```

这叫来源链。没有来源链的内容即使写着“根据官方手册”，数据库也不允许审核通过。

## 为什么页码还不够

同一个 PDF 第72页以后可能同时存在：

- pypdf 读取的文字层；
- Docling 整理的版面结构；
- 光学识别结果；
- 人工转录结果。

它们的页码相同，正文、表格顺序、工具版本和产生时间不同。只保存 `page_number = 72`，无法说明助手究竟采用了哪一份。

## 三个方案怎样选

| 方案 | 优点 | 关键问题 | 结论 |
|---|---|---|---|
| 只存页码 | 最简单 | 无法区分工具结果 | 淘汰 |
| 片段直接连一个提取结果 | 查询简单 | 只能连接一页 | 不选 |
| 独立来源关系表 | 支持多页、多工具和顺序 | 多一张表 | 采用 |

不要因为“表少”就默认设计更好。这里多一张表换来了多来源、可排序和历史可追踪，复杂度有明确业务价值。

## 三层组合外键怎么理解

把组合外键理解成三次核对身份证：

1. 这个片段确实属于它声称的资料版本；
2. 这个页面确实属于同一个资料版本；
3. 这个提取结果确实属于这个页面。

因此以下数据都会被数据库拒绝：

- 05版片段接04版资料编号；
- 声称05版，但页面实际来自04版；
- 页面写第72页，提取结果实际来自第50页；
- 同一片段出现两个“第1来源”；
- 同一提取结果重复挂到同一片段。

## 为什么既用外键又用触发器

外键擅长保证“编号之间的关系真实存在”，例如提取结果必须属于某个页面。普通检查约束只适合当前一行，不能去另一张表数“这个片段有没有来源”。

所以分工是：

- 组合外键：片段、版本、页面和提取结果不能串线；
- 唯一约束：来源顺序和提取结果不能重复；
- 检查约束：来源顺序必须大于0；
- 触发器：没有来源不能通过，审核后不能改，页面提取结果不能覆盖。

这不是“所有规则都塞触发器”。能用外键和唯一约束表达的规则优先用更直接的约束。

## 正确的业务写入顺序

```text
第一步：创建待审核片段
第二步：绑定具体来源
第三步：人工核对正文和分类
第四步：更新为已通过
```

不能直接插入“已通过”片段。数据库会先检查它是否已有来源，而一条还不存在的片段不可能提前拥有来源。

## 为什么通过后不允许原地修改

假设审核人确认的是“OHF：设备过热”，后来有人直接把同一行改成另一段文字。审核记录还在，但审核对象已经变了。

本项目采用“追加新记录”原则：

- 新工具结果新增一条页面提取记录；
- 片段纠错新建一个候选并重新审核；
- 原来的已通过或已驳回记录保持不变。

这样可以回答“某张旧工单当时使用的到底是哪一版证据”。

## 真实OHF验证

R90没有手写一份假页面，而是导入真实的440页提取文件，从数据库找到 NVE41300 中文05版 PDF 第72页的 `pypdf 6.10.0` 结果，核对页面文字指纹，并把 `[设备过热] OHF: 设备过热` 建成故障定义片段。

审核后从片段反查得到：故障码 OHF、PDF 第72页、提取器 pypdf、版本 6.10.0、审核状态已通过。这才是完整成功路径。

## 旧库为什么可能被迁移阻断

新增触发器只能管未来数据。如果旧库已有无来源的已通过片段，直接升级会留下一个看似合规、实际没有证据的漏洞。

迁移 013 选择阻断并报告，不自动猜来源，也不修改旧审核状态。迁移失败在这里是安全功能，不是程序质量差。

## 实际产品怎样做

Microsoft Azure AI Search 的结构化切片会同时保存片段和用于识别其来源的父级字段；Google Cloud Document AI 的文档格式保存修订关系，并区分修改来自人还是处理器；IBM watsonx Orchestrate 的文档复核让用户把提取值与源文档并排检查。我们从这些产品确认“片段父级、处理版本、人工来源核对”都有实际业务背景，再根据工业手册场景做更严格的版本—页面—提取结果链。

## 本节应该记住的六句话

1. 页码不是完整来源，具体提取结果才是。
2. 多对多关系需要独立关系表，不能把多个编号塞进一格文字或数组逃避关系约束。
3. 受约束的重复字段可以用于组合外键，阻止跨版本拼接。
4. 外键管身份关系，触发器管需要查看其他记录的流程门禁。
5. 审核通过后的正文、分类、来源和提取结果都要冻结。
6. 迁移遇到无法可靠推断的旧数据时，阻断比自动猜测安全。
