# 第三天教学04：为什么相似度高不等于资料里有答案

## 最重要的结论

向量模型做的是“找最像的片段”。即使六个片段都答非所问，它也会选一个最像的。相似度0.86只是一个分数，不是“资料包含答案”的概率。

## 我们怎样避免自己骗自己

1. 从40题开发集提出0.86候选阈值；
2. 不在原40题上验收；
3. 新建24题留出集；
4. 第一次运行前保存题库摘要、阈值和门槛；
5. 运行后无论结果如何都不改题；
6. 按三类失败逐题复盘。

## 结果教会了什么

- 11/12可回答题被正确接收；
- 10/12无答案题被正确拒答；
- “保修售后”和“风扇备件编号”仍越过阈值；
- 一道断电隔离题不仅低于阈值，第一名还排错。

所以问题不是简单把0.86改成0.87。阈值同时影响两类错误：太低会乱答，太高会把真正有答案的问题也拒绝。

## 当前系统为什么仍不会直接生成危险方案

检索命中只是候选。后面的风险门还会检查知识用途：只有经过审核且标为“允许低风险指导”的证据才允许形成方案；定义、阈值、警告或工程师专用资料都不能因为向量分高就变成操作步骤。

## 应该记住的面试说法

> 我没有把余弦相似度当置信概率。开发集上0.86看似能分开正负样本，我先冻结24题留出集再运行，结果无答案拒答只有83.3%，所以没有上线阈值。错误召回仍要经过数据库用途和风险门，不能自动变成方案；下一步会评估“候选是否直接回答问题”的独立判断，并使用新的留出集验收。
