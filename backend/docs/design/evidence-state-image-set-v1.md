# 证据状态配图集 v1

## 用途与边界

本图集用于本地多工单运营台的“当前工单证据”模块。五张新增图片均由内置图像生成工具生成，是帮助用户快速理解状态的视觉示意，不是客户现场照片、官方手册页面或数据库证据。

页面必须明确区分：

- `verified_manual`：角标为“来源示意”，证据事实仍来自正式资料身份、页码和逐字摘录；
- 其他五类：角标为“状态示意”，业务结论仍来自后端 `evidencePreview`，图片不能单独证明结论。

## 最终提示词集

五张图统一使用：工业维修证据面板、16:9 横向构图、电影感工业产品摄影与技术插画结合、真实金属和纸张质感、深黑与石墨色背景、克制的状态强调色；禁止人物、品牌标志、可读文字、数字、水印、界面覆盖和装饰性科幻全息效果。

### 高危阻断

过热的通用变频器被明亮的橙红色安全挡杆和实体急停装置隔离，保护回路已停止，画面明确区分危险热区与安全屏障。

### 证据不足

官方设备手册与变频器位于一侧，空白维修记录夹和备件货架位于另一侧，中间存在清晰断裂，表达官方资料不包含本机维修日期或厂区库存。

### 资料版本冲突

同一设备资料的两个不同版次相对摆放，以不同颜色装订标签和不可读版次印章区分，中间由橙色冲突线隔开，表达两个版本不能互相替代。

### 厂区权限阻断

两个厂区区域被实体权限门和上锁工业柜分隔，数据线在越界前被阻断，受保护设备与资料留在授权区域内。

### 尚未检索

通用变频器已经挂上空白工单标签，旁边的官方手册仍关闭，扫描轨道处于未启动状态，表达设备已建单但检索链尚未开始。

## 验收规则

1. 六种状态的资源路径必须唯一且文件存在；
2. 切换工单时图片路径必须随 `evidencePreview.state` 改变；
3. 图片必须成功加载并拥有描述业务含义的替代文字；
4. 非已核验状态不得因为配图而获得页码或手册摘录；
5. 生成图只能标为状态示意，不能称为真实现场证据。
